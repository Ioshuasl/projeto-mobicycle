\# Mercado Pago MCP Server \*\*Mercado Pago MCP Server\*\* implements the open standard \[Model Context Protocol (MCP)\](https://modelcontextprotocol.io) to facilitate access to Mercado Pago APIs and tools for AI agents or LLMs in compatible development environments. This server acts as an intermediary, translating resources from the Mercado Pago ecosystem into tools, or executable functions that artificial intelligence applications can invoke to perform actions, extending the traditional capabilities of Mercado Pago APIs to automated or AI-assisted flows. With this, Mercado Pago MCP Server allows you to simplify the integration process, use the available documentation to implement or improve code, and optimize its operation through natural language interactions without the need for manual implementations. Explore our documentation to learn how to make the connection, what tools the Mercado Pago MCP Server has available, and how to use them to enhance your integrations in our use cases. ## Prerequisites Before you start using the server, make sure you have your environment ready: | Requirement | Description | |-|-| | \*\*Client\*\* | The connection to Mercado Pago MCP Server is remote, so you need to choose a client from which to interact with the assistant. The solution is available for the main AI agents: Cursor (version 1 or higher), VS Code, Windsurf, Cline, Claude Desktop or Code, and ChatGPT. In all cases, make sure you have the latest available version. | | \*\*Credentials\*\* | Credentials are unique access keys with which we identify an integration in your account, and will be necessary to connect with some clients. Check the \[documentation\](https://www.mercadopago.com.br/developers/en/docs/credentials) for more information. |
